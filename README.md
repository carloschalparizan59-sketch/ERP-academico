# 🔧 ERP Académico para Talleres Automotrices

![Estado](https://img.shields.io/badge/estado-en%20desarrollo-yellow)
![Licencia](https://img.shields.io/badge/licencia-MIT-blue)

Sistema ERP orientado a **integrar y automatizar** los procesos administrativos, operativos y financieros de talleres automotrices.

El proyecto está diseñado inicialmente para una empresa del sector automotriz, con la posibilidad de adaptarse posteriormente a otros talleres.

## 🎯 Objetivo

Centralizar la información del taller en una sola plataforma para reducir errores, ahorrar tiempo y facilitar la toma de decisiones.

## 🧩 Módulos

| Módulo | Descripción | Estado |
|---|---|---|
| Clientes y vehículos | Registro de clientes e historial de cada vehículo | ⏳ Pendiente |
| Órdenes de trabajo | Creación y seguimiento de reparaciones | ⏳ Pendiente |
| Inventario | Control de repuestos e insumos | ⏳ Pendiente |
| Facturación | Emisión de facturas y control de pagos | ⏳ Pendiente |
| Reportes | Indicadores financieros y operativos | ⏳ Pendiente |
